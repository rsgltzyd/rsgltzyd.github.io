# 双端视觉验证 (Responsive Visual Verification) 指南

该 Skill 为雨霖铃手绘个人杂志站点提供跨端（桌面 1280px+ / 移动端 375px~430px）及多主题（深色/浅色）的视觉与交互验证流程。

## 1. 验证维度矩阵

| 模块 | 桌面端 (Desktop ≥ 768px) | 移动端 (Mobile ≤ 640px) |
| :--- | :--- | :--- |
| **顶栏 Masthead** | 三按钮明暗切换（浅色/深色/自动）；手绘天空居中：浅色（双云+笑脸太阳紧邻导航）/ 深色（星群+月牙紧邻导航）；底部手绘分割线 | 单按钮切换（🌙/☀️ 一键切换）；单行单列不折行；品牌靠左导航靠右；隐藏天空以保单行精简 |
| **首屏人物 Figure** | 纯净底色（无灰底框线）；无左右箭头；10 款场景按键 5x2 矩阵网格（圆角描边，当前实心反色） | 纯净底色；支持水平滑动手势（Swipe Left/Right）；10 款场景标签 5 列自适应平铺 |
| **标题与排版 Hero** | 桌面端两行断句「做有趣的<br />东西。」，「东西。」专属波浪下划线；文案「先玩一局，再慢慢读。」 | 移动端主标题单行展示；缩减上间距，人物与标题快速进首屏 |
| **信息架构 Views** | 首页：仅人物 + 精选文章；游戏与关于拆为同页独立视图 | 点击顶栏「01 游戏」「03 关于」即时切换同页独立视图；点击品牌或「返回首页」平滑回首页 |
| **小游戏 Console** | 游戏标签单行平铺；居中浮层窗口展开 | 游戏标签 2 列网格；触控按键描边高对比反馈；浮层窗口适配 95vw |
| **游戏提示 Overlay** | DOM 叠层覆盖于 Canvas 之上，字迹清晰锐利，无模糊 | 同样使用 DOM 叠层，点击蒙层直接开局或复活 |
| **底色覆盖 100dvh** | `journal-paper` 铺满屏幕底色 | `min-height: 100dvh`，无白底外露，全覆盖夜间手绘纸质色 |

## 2. 自动化验证脚本运行

通过命令直接执行全套 DOM、CSS、主题与响应式标记的自动化断言：

```bash
npm run verify
# 或
node scripts/visual-verify.mjs
```

## 3. 视觉截图规范（带浏览器环境）

若在包含图形化浏览器依赖的环境中截取双端效果图：

```bash
# 桌面端 (1280x800)
# - 浅色模式: 检查太阳、云彩、三按钮主题、文章折叠
# - 深色模式: 检查月牙、星星、深色背景纸全覆盖、无漏白

# 移动端 (390x844 - iPhone 14/15 视口)
# - 检查顶栏单行不折行、单按钮主题切换
# - 检查主标题「做有趣的东西。」单行展示
# - 检查人物卡片进入首屏无需向下滚动
# - 检查小游戏 2 列标签与触控描边
# - 检查居中浮层窗口与全屏图标
```
